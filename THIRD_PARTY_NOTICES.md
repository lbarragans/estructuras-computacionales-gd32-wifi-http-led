# Avisos de componentes de terceros

Este repositorio contiene únicamente la aplicación educativa, documentación,
configuración de VS Code y una utilidad de ensamblado.

No redistribuye:

- GD32VW55x Wi‑Fi & BLE SDK;
- bibliotecas binarias o firmware RF de GigaDevice;
- GD32 Embedded Builder/Nuclei toolchain;
- GD32 ISP CLI;
- FreeRTOS, lwIP, mbedTLS u otros componentes incluidos por el SDK;
- drivers CH340.

Cada componente conserva la licencia del titular y debe obtenerse de su canal
oficial. La presencia de nombres o rutas de integración no concede derechos de
redistribución. Revise los archivos de licencia incluidos en cada descarga.

El HTML local y el código de `VendorApp` están destinados a enseñanza. Antes de
adoptarlos en un producto, realice revisión jurídica, seguridad y licenciamiento.
